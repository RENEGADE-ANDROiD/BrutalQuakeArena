Brutal Quake overlay for Map-Center Q30th Jam
=============================================

Copy these files ON TOP of rerelease/mc_q30th_jam/ (the jam map pack).
Do not put them in id1. Do not put game mc_q30th_jam in Steam Launch Options.

1. Install the jam as rerelease/mc_q30th_jam
2. Copy this folder's contents into rerelease/mc_q30th_jam
3. Launch the remaster, open the console, type: game mc_q30th_jam
4. Start a new game or: map start
5. Turn Enhanced Models off (Options > Display)

Brutal melee, meathook, and gore work.

Hub completion tracking and the start-map boss lock are not in this
overlay (the jam still plays; the boss portal stays as mapped).
Return to the hub from any map: changelevel start

This overlay does not include the jam maps.
