Brutal Quake overlay for Tremor
================================

Copy these files ON TOP of rerelease/tremor/ (the Tremor map pack).
Do not put them in id1. Do not put game tremor in Steam Launch Options.

1. Install the Tremor map pack as rerelease/tremor
2. Copy this folder's contents into rerelease/tremor
3. Launch the remaster, open the console, type: game tremor
4. Start a new game or: map start
5. Turn Enhanced Models off (Options > Display)

Brutal melee, meathook, and gore work. Tremor extras:

  impulse 51  Shotgun Start (inventory resets between maps)
  impulse 53  give gold key
  impulse 54  give episode 1 rune
  impulse 55  give episode 2 rune
  impulse 56  give episode 3 rune
  impulse 57  give episode 4 rune
  impulse 58  give silver key  (was 52; 52 is the meathook)

impulse 9 still gives all weapons. impulse 11 still cycles runes.

Tremor maps use the same BSP names as original Quake, so campaign
achievements may unlock. Use New Game on official episodes for those.

This overlay does not include Tremor's maps or music.
